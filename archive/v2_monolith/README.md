# 归档版本：v2.0 通用知识引擎单体版 (Transitional Monolith)

> **归档日期**：2026-10-08  
> **归档说明**：本目录封存了在实施物理模块化重构之前的 v2.0 单文件单体（Monolithic Single-File）最终完整版本。

---

## 包含核心特性

1. **三维正交架构落地**：业务大组 (Group) × 细分类别 (Category) × 认知层级 (Layer 1~3)。
2. **知识精读大厅 (Study Hub)**：3-Step 矩阵联动中控台、三层嵌套卡片树、遮挡自测模式、单卡专项突破。
3. **题库工坊 (Deck Studio)**：Markdown 与可视化表单双向实时同步编辑器、AST 解析器、5-3-10 健康度实时检测。
4. **题库管理中心 (Deck Manager)**：多题库切换、预设保护、原地编辑、防误触二次确认删除。
5. **内置全量题库**：
   - 英语动词形态全规则库 (`deck_verbs`)
   - 计算机网络状态码 (`deck_http`)
   - Python 核心数据结构 (`deck_python`)
6. **科学记忆引擎**：基于艾宾浩斯 / SM-2 演进的记忆稳定度模型。
7. **架构门禁中控**：内置 `FE-*` 门禁自检弹窗。

---

直接在浏览器中双击打开 [`index.html`](./index.html) 即可 100% 离线运行。
