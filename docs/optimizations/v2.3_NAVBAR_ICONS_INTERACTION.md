## 一、 用户关注的核心问题诊断与优化结论

针对用户提出的三个核心设计问题，结合前沿工业级界面规范（`界面设计核心规范.md`、`色彩设计核心.md`、`图标设计规范与流程-精简哲学.md`），系统诊断与决策如下：

| 用户提问 | 诊断现状 | 优化结论 | 核心解决动作 |
| :--- | :--- | :---: | :--- |
| **1. 导航栏是否需要优化？** | 现导航左侧既显示题库大标题，又紧跟同名下拉框（双重冗余）；缺少全局一级视图（控制台/精读/法典）切换；左侧双行垂直堆叠导致高度臃肿（>72px），左右重心失衡。 | **必须优化** | **单行流式 60px 标顶**；品牌与题库切换解耦（Logo + 题库胶囊 Pill）；正中央引入三段式 Segmented Control 导航；右侧状态收拢。 |
| **2. 彩色图标是否需要使用中性色图标优化？** | 当前界面散落大量系统彩色 Emoji（🌐, ⚙️, ⏰, 🎯, ⚔️, 🛡️, 📚, 💾, 🔥 等）。跨平台（Windows/Mac/Android）形状与颜色不一，颜色饱和度刺眼破坏工业暗色质感，且无法通过 CSS `currentColor` 平滑响应悬停/激活态。 | **必须优化** | **全站废黜彩色 Emoji**；采用 100% 离线零依赖的 **内联单色矢量 SVG 符号库**，基准色为中性色 `text-neutral-400`，交互时平滑响应高亮。 |
| **3. 视觉焦点交互逻辑是否需要优化？** | 顶部“今日智能推荐”横幅配有高饱和实色 CTA（“开始艾宾浩斯复习”），下方第 1 张模式卡片（“艾宾浩斯智能复习”）同样配有高亮实色 CTA，形成同质竞争；卡片内部既有卡片点击又有文字按钮，存在意图冲突；数据看板五彩斑斓分散注意力。 | **必须优化** | **确立 Rule of One 绝对焦点**：Banner 作为首要任务（Primary Hero）；对应卡片施加**微光联动呼吸环 (Hero Ring)**；卡片消除内部文字按钮，全卡作为单一 Action Card；统计数据统一中性色高亮。 |

### 1. 导航栏架构与信息解耦重构 (Navbar Spec)

#### 1.1 现状硬伤与消除
- **消除双重命名冗余**：不再在 H1 中硬编码当前选中题库名称，H1 确立为永恒应用品牌：`Universal Knowledge Engine`。
- **题库切换胶囊化 (Pill Dropdown)**：在品牌右侧放置一个精致的次级 Surface 胶囊按钮 `[ 📦 HTTP状态码 ▾ ]`，点击展开题库切换与新建菜单。题库右侧紧跟中性色齿轮图标 `[ ⚙️ 管理 ]`。
- **中心 Segmented Control 导航器**：
  - 承载全站三大大核心一级路由：
    - `[ 仪表盘 (Dashboard) ]` —— 战役、模式、今日推荐与掌握雷达；
    - `[ 知识精读 (Study Hub) ]` —— 结构化树状浏览、遮挡自测记忆流；
    - `[ 知识工坊 (Deck Studio) ]` —— Markdown AST 双向编辑、CRUD 维护。
  - 带有平滑滑块背景指示器（Active Indicator），高亮当前激活视图。
- **高度与空间规范**：
  - 垂直高度收敛为标准的 `h-14` (56px) ~ `h-16` (60px) 单行水平流式布局。
  - 采用 `sticky top-0 z-50` 搭配微弱毛玻璃模糊（`backdrop-blur-md bg-neutral-950/80`）。

### 2. 中性色矢量 SVG 图标库体系 (Monochrome Vector Icons)

#### 2.1 精简哲学与设计规范
依据《图标设计规范与流程-精简哲学》：
1. **尺寸规范**：基准统一为 `16×16` (sm)、`20×20` (md) 与 `24×24` (lg) 三个阶梯。
2. **线条与填充**：统一采用 1.5px / 2px 描边或平滑中性填充，矢量 Path 经过像素对齐（Pixel Snapping）。
3. **颜色响应**：图标自身不设定任何硬编码十六进制色值，统一声明 `fill="currentColor"` 或 `stroke="currentColor"`。
   - 默认静止态：继承父级中性文字颜色（`text-neutral-400`）；
   - 悬停/激活态：平滑随父级文本变亮（`text-neutral-100` 或 `text-primary-400`）。
4. **100% 离线交付**：零网络请求，不依赖任何外部 CDN 字体库或第三方 npm 图标包，直接内联为 SVG Symbol 或 JavaScript 模板函数。

### 3. 视觉焦点与交互逻辑闭环 (Visual Focus & Micro-interaction)

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        Rule of One 视觉焦点导流链路                     │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│   [ 🌟 今日推荐复习横幅 (Primary Hero) ] ────────────────────────┐     │
│   • 唯一主对比实色按钮: [ ⚡ 立即复习 (5条到期) ]               │     │
│                                                                  │     │
│                                                                  │     │
│   [ 下方模式选择卡片网格 ]                                        │     │
│   ┌───────────────────────────┐     ┌──────────────────────────┐ │     │
│   │ 艾宾浩斯智能复习 (Hero Ring)│     │ 弱点专项突击             │ │     │
│   │ [呼吸边框 / 微光联动]     │     │ [中性静止态 Surface 2]   │ │     │
│   │ (点击整张卡片直接启动)     │     │ (点击整张卡片直接启动)   │ │     │
│   │ ➔                         │     │ ➔                        │ │     │
│   └───────────────────────────┘     └──────────────────────────┘ │     │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```

#### 3.1 消除 Banner 与第一张卡片的同质争焦
- **现象痛点**：顶部 Banner 是“智能复习”，左下方第一张模式卡片也是“智能复习”。两个强蓝色按钮并排，用户产生疑惑：“我到底点哪个？”
- **解法 —— 首要焦点归属与视觉层级联动**：
  1. **Banner 享有全屏第一视觉顺位 (Primary)**：背景施加柔和径向渐变（`radial-gradient`），主按钮使用全站最高明度与主品牌色（`bg-primary-500 text-white shadow-lg`），并文案明确当前待复习条数（“今日有 5 个知识点待巩固”）。
  2. **对应模式卡片施加“联动微光环” (Hero Ring)**：下方对应的“艾宾浩斯智能复习”卡片自动挂载次级高亮环（`ring-1 ring-primary-500/40 shadow-primary-500/10`），卡片内部**取消文字按钮**，而是呈现“当前推荐模式”小角标，向用户明确传达：“Banner 所推荐的就是这一张卡片，两者同源”。

#### 3.2 模式卡片单体化交互 (Action Card 纯净化)
- **彻底去除卡片内部的多余按钮**：卡片内部不再放置带有边框的 `<button>`（避免“卡片能点，里面的按钮也能点”的认知分裂）。
- **整卡可点击 + 交互微动效**：整张卡片作为一个可点击的 Surface 2 容器。
  - **默认静止态**：Surface 2 (`#131c31`)，边框中性微弱透明（`border-white/5`）；
  - **悬停态 (Hover)**：Surface 3 (`#1a2642`)，卡片轻微上浮（`translate-y-[-2px]`）；
  - **右上角导向指示器**：单色中性色小箭头 `→`，悬停时触发微动效位移（`group-hover:translate-x-1 group-hover:text-primary-400`）。

#### 3.3 数据看板数值降噪与纯净化
- 统计数字（如“总条目数 42”、“掌握率 85%”、“待复习 5”）全部收敛为**高对比中性白（`text-neutral-100`）**，配合清晰的字阶（`text-2xl font-bold`）。
- 仅保留极小尺寸的次级标签或状态微圆点（如绿色的已掌握 dot、黄色的待复习 dot）传达语义，彻底杜绝“蓝一块、黄一块、绿一块、紫一块”的彩虹仪表盘噪音。

## 三、 架构实现方案与代码修改清单

### 1. 结构与视图层 (`app/app-shell.html`)
- 重构 `<header>` 为单行 60px 结构：
  - 左侧：App Brand Title + 题库选择 Dropdown + 题库管理按钮。
  - 中间：Segmented Control 容器（`nav-tab-dashboard`, `nav-tab-study-hub`, `nav-tab-deck-studio`）。
  - 右侧：连续打卡 Badge + 数据存档 Dropdown。
- 重构 Dashboard 模式卡片列表：
  - 替换所有 Emoji 为内嵌 SVG 图标。
  - 去除卡片内部重复按钮，重写为统一的 Action Card 结构。
  - 为推荐卡片动态附加 Hero Ring 联动标识。

### 2. 路由控制器 (`app/router.js`)
- 扩展路由同步逻辑：当视图在 `dashboard`、`study-hub`、`deck-studio` 之间切换时，自动同步 Segmented Control 滑块的高亮位置与状态。

### 3. 图标库服务 (`design-system/icons/icons.js` 或内联 SVG)
- 建立统一的单色矢量 SVG 字典对象 `Icons`，对外暴露 `renderIcon(name, className)` 方法，零网络请求、零外部依赖。

### 4. 打包构建与门禁验证
- 运行打包脚本 `node scripts/bundler.mjs`，确保单文件构建无缝内联。
- 扩充门禁规则（`FE-NAV-001` 与 `FE-ICON-001`），执行 `node gates/run-gates.mjs` 确保 100% 通过。
- 内置浏览器校验视觉与操作闭环。
