## 一、 问题背景与根因剖析

### 1. 现象描述
用户反馈在题库编辑和导入工坊（`modal-deck-studio`）中：
- 点击顶部视图切换按钮（“纯可视化”与“纯 Markdown”）时，页面无任何响应或单侧无法正常全宽展开；
- 工坊停留在默认分屏模式，单视图编辑不可用。

### 2. 根因剖析 (Root Cause)
经过排查 `app/main.js` 与 `app/app-shell.html`，发现存在以下三处不一致：
1. **DOM ID 查取错配**：
   - `app/main.js` 中 `setStudioViewMode(mode)` 函数检索的 DOM 元素为：
     - `studio-visual-col` 与 `studio-markdown-col`；
     - `btn-studio-view-visual`、`btn-studio-view-split`、`btn-studio-view-md`。
   - 而在 `app/app-shell.html` 中，实际面板元素 ID 为：
     - `studio-visual-pane` 与 `studio-markdown-pane`；
     - `btn-view-split`、`btn-view-visual`、`btn-view-markdown`。
   - 导致 `document.getElementById('studio-visual-col')` 恒为 `null`，函数第一行触发保护性 `if (!visualCol || !mdCol) return;` 提前退出，所有模式切换与样式修改均未执行。
2. **模式参数别名不一致**：
   - 按钮 `onclick` 传入的参数为 `'markdown'`，但在 JS 中旧分支判断为 `else if (mode === 'md')`。
3. **视觉图标与 v2.3 规范脱节**：
   - 顶部视图切换按钮原本仍夹带彩色 Emoji（`🔀 分屏联动`、`🎨 纯可视化`、`📝 纯 Markdown`），未适配 v2.3 确立的 100% 单色矢量 SVG 规范。

## 二、 修复与优化实施方案

### 1. 修复 DOM ID 映射与参数兼容 (`app/main.js`)
在 `KnowledgeMasterApp.prototype.setStudioViewMode(mode)` 中：
- 修正获取面板为 `studio-visual-pane` 与 `studio-markdown-pane`；
- 修正获取按钮为 `btn-view-split`、`btn-view-visual`、`btn-view-markdown`；
- 兼容 `mode === 'markdown' || mode === 'md'`。

### 2. 动态布局与全宽自适应逻辑 (`w-full` / `w-1/2`)
- **纯可视化模式 (`visual`)**：
  - `visualPane`：移除 `hidden`、`w-1/2`、`border-r`，添加 `w-full`；
  - `mdPane`：添加 `hidden`，移除 `w-full`、`w-1/2`；
  - 左侧表单独占 100% 宽度，提供宽屏下舒适的节点表单录入体验。
- **纯 Markdown 模式 (`markdown`)**：
  - `visualPane`：添加 `hidden`，移除 `w-full`、`w-1/2`；
  - `mdPane`：移除 `hidden`、`w-1/2`，添加 `w-full`；
  - 右侧 Markdown 编辑器独占 100% 宽度，适合大段代码与文本沉浸式撰写与批量粘贴。
- **分屏联动模式 (`split`)**：
  - `visualPane`：移除 `hidden`、`w-full`，恢复 `w-1/2` 与右边框 `border-r border-slate-800`；
  - `mdPane`：移除 `hidden`、`w-full`，恢复 `w-1/2`；
  - 两侧保持 50% 均分，左边改右边自动响应，右边改左边定时解析。

### 3. 单色矢量 SVG 按钮组与高亮响应 (`app/app-shell.html`)
- 将三个切换按钮的图标升级为标准 Feather/Heroicon 风格单色 SVG（`currentColor`）：
  - **分屏联动**：矩形分栏双列图标；
  - **纯可视化**：单列组件排版图标；
  - **纯 Markdown**：代码/文稿文件图标。
- 动态状态高亮：激活按钮应用 `bg-indigo-600 text-white font-medium shadow`，未激活应用 `text-slate-400 hover:text-white`。
