# 08. 知识体系三维分层规范：业务分组 × 细分类别 × 认知层级 (3D Knowledge Architecture Spec)

---

## 一、为什么必须彻底分离「分组、分类、层级」？

在最初的原型设计中，系统仅将知识划分为平铺的类别（Categories），导致两个致命痛点：
1. **大分类平铺堆砌（认知过载）**：当题库拥有 8~15 个细分类别时，顶部导航栏充斥着长串药丸按钮，无法展现知识领域的宏观脉络（如：动词的「规则变形」、「不规则五型」、「三单特例」被混为一谈）。
2. **认知深度扁平化（无法因材施教）**：基础概念（如 cost→cost→cost）与高难度特例陷阱（如 401 与 403 辨析、除斥期间 90 天）混排，学习者无法按由浅入深的阶梯进行递进攻克。

因此，通用知识复习引擎将知识架构严格解耦为 **三维正交坐标系**：
```
知识库 (Deck)
 └── 📦 业务大组 (Group)        —— 宏观板块与学科领域
      └── 🏷️ 细分类别 (Category)   —— 具象规则与同胞干扰池
           └── 🪜 认知层级 (Layer)     —— 认知深度与考察阶梯
                └── 📇 概念词条 (Entity) —— 最小原子考点卡片
```

## 二、三维正交体系定义与职责边界

| 维度 | 术语 | 粒度规模 | 核心职责 | 在界面中的呈现形态 |
| :--- | :--- | :--- | :--- | :--- |
| **维 1: 业务大组** | **Group** | 1 ~ 5 个 / 题库 | **学科宏观业务板块**。划定大的知识范畴，例如「一、规则变形与分词规律」、「二、不规则动词核心记忆法」、「三、第三人称单数」。 | 学习大厅顶部 **STEP 1** 分组药丸按钮；卡片列表的 **顶级深色卡片容器**，带「专项练习此大组」入口。 |
| **维 2: 细分类别** | **Category** | 3 ~ 10 个 / 分组 | **具象规则分类与同胞池容器**。定义具体规则集合（如「AAA型同形」、「-ic加k特例」）。同分类条目互为干扰项生成池（必须 $\ge 4$ 条）。 | 学习大厅顶部 **STEP 2** 细类药丸按钮（按所选分组联动）；卡片列表中的 **二级板块容器**。 |
| **维 3: 认知层级** | **Layer** | 固定 3 级 (L1/L2/L3) | **认知加工深度阶梯**。<br>• **Layer 1 (基础认知)**：死记硬背与直觉辨识<br>• **Layer 2 (规律运用)**：推导计算与模式归纳<br>• **Layer 3 (陷阱与特例)**：易混易错、反常特例与边界条件。 | 学习大厅顶部 **STEP 3** 阶梯按钮；卡片列表中的 **三级彩色楼梯横条**（🌱/🌿/🔥），支持「只练此层」。 |

## 三、Markdown 与数据模型规范映射

为了保持纯文本 Local-First 的极简性与可读性，Markdown 大纲语法与三维架构 100% 直观对齐：

### 1. 标准 Markdown 大纲语法结构
```markdown
# 📚 题库标题 (Deck)
> 题库简要说明

## [分组] 一、业务大组名称 (Group)

### [分类] 细分类别名称 (Category)
#### [Layer 1] 基础认知
- **概念/原型**: 核心答案
  - *注记*: 辅助助记词
  - *考点*: 提问引导词
  - *解析*: 详细规则推导
  - *误区*: 常见混淆陷阱
  - *混淆*: 强干扰同胞词

#### [Layer 2] 规律运用
- **概念**: 核心答案
  ...

#### [Layer 3] 陷阱与特例
- **概念**: 核心答案
  ...
```

### 2. 语法容错与向下兼容
- **省略分组**：若用户直接编写 `## [分类] 名称`，引擎自动归入默认分组 `「核心知识板块」`。
- **行内指定分组**：支持 `## [分类] AAA型 (分组: 不规则记忆)` 或 `### [分类] 客户端错误 [分组: 4xx]`。
- **层级省略**：未指定 Layer 的词条默认继承最近的 Layer，或默认归入 `Layer 1`。

## 四、学习大厅 (Study Hub) 三阶矩阵中控台

为了让学习者随心所欲地多维度筛选、逐层穿透，学习大厅顶部设置 **三步中控过滤矩阵**：

```
+---------------------------------------------------------------------------------------------------+
|  [🔍 快速检索概念/解析...]                           [👁️ 遮挡答案自测: 开] [📋 原始大纲] [🔄 重置] |
+---------------------------------------------------------------------------------------------------+
|  STEP 1: 📦 业务分组  [全部分组] [一、规则变形与分词规律] [二、不规则动词核心记忆法] [三、第三人称单数] |
|  STEP 2: 🏷️ 细分类别  [全部分类] [-ic加k] [现在分词/动名词] [规则过去式] (随 STEP 1 动态筛选联动)       |
|  STEP 3: 🪜 认知层级  [全部层级] [🌱 L1 基础认知] [🌿 L2 规律运用] [🔥 L3 陷阱特例]                  |
+---------------------------------------------------------------------------------------------------+
```

### 联动与穿透逻辑：
1. **单项点击联动**：
   - 点击 STEP 1 的某大组（如「二、不规则动词核心记忆法」），STEP 2 立即仅展示属于该大组的细分类别（AAA型、AAB型、ABA型、ABB型、ABC型）。
   - 点击 STEP 3 的「🔥 L3 陷阱特例」，列表瞬间只保留所有分类下的高难度特例卡片。
2. **专项刷题穿透 (Drill Entrance)**：
   - 📦 **大组突破**：点击大组卡片头部的 `🚀 专项练习此大组`，立即打包该大组名下的所有词条进入竞技场。
   - 🏷️ **细类突破**：点击分类卡片头部的 `练习此分类 →`，仅针对该具体细类进行专注复习。
   - 🪜 **层级突破**：点击三级阶梯条上的 `只练此层 →`，一键进行全库或分类下的盲区扫荡。
   - 🎯 **单卡突破**：点击任意单卡右下角的 `🎯 专项突破`，针对单个弱项词条进行集中巩固。

## 五、题库工坊 (Deck Studio) 双向联动支持

在题库工坊（Deck Studio）的 **可视化/MD 双视图** 中，三维架构得到完整支持：

1. **可视化表单视图**：
   - 每个分类卡片头部显式拆分为：`📦 业务分组 input` 和 `🏷️ 细分类别 input`。
   - 每一个概念条目均配备 `🪜 认知层级 Select` 下拉选择框（L1: 基础 / L2: 规律 / L3: 特例陷阱）。
   - 任何改动即时通过 `onCategoryGroupChange` 和 `onVisualChange` 毫秒级重构内部 AST。
2. **Markdown 代码视图**：
   - 序列化生成器 `serializeDeckToMarkdown` 严格按照 `H1(Deck) -> H2([分组]) -> H3([分类]) -> H4([Layer]) -> List Item` 输出。
   - 输入 Markdown 文本时，AST 解析器毫秒级识别 `## [分组]`、`### [分类]` 与 `Layer`，并动态更新底部健康度检测条：
   - 示例：`🟢 3大组 · 8细类 · 45词条 · 结构健康 (符合 5-3-10 标准)`。
