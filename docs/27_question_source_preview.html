五大设计模式协同架构矩阵

Core Architecture Topology
1. 策略模式 (Strategy)

将各模式题目筛选排序抽离为独立策略类。彻底消除大坨 if-else，保证出题算法高聚合、可插拔。

2. 规约模式 (Specification)

收口“错题”、“到期”、“生锈”判断公式。Dashboard、角标、横幅与出题 100% 共享规约，消除口径打架。

3. 管道模式 (Pipeline)

四级干扰项合成流：强混淆优先注入 $\to$ 同形态同胞对齐 $\to$ 领域自适应退火 $\to$ 洗牌，解决跨时态破绽。

4. 工厂模式 (Factory)

集中管理策略实例与别名归一化（如 daily / daily_review），支持开闭原则扩展自定义模式。

5. 快照隔离模式 (Snapshot)

保存会话上下文使“再来一局”不丢失专项范围；沙盒分层打上隔离标，防止越权解锁主线天梯。
