## 一、核心玩法循环 (Core Gameplay Loop)

本系统采用“**直觉刺激 → 即时反馈 → 规则归纳 → 艾宾浩斯固化**”的四步闭环模型，兼顾游戏紧张刺激感与严肃学习效果。

                         │ • 倒计时进度条 (依据模式配置)    │

## 二、题型设计与交互规范

系统内置 4 类核心题型，针对不同认知阶段采用不同测试形式：

### 1. 题型一：高仿陷阱四选一 (Trap Buster Choice)
- **场景**：主线闯关、每日复习、极速模式。
- **题目呈现**：
  > 单词原形：**mimic**  
  > 目标形态：**现在分词 (doing)**  
  > [1] mimicing &nbsp;&nbsp;&nbsp;&nbsp; [2] mimicking &nbsp;&nbsp;&nbsp;&nbsp; [3] mimiking &nbsp;&nbsp;&nbsp;&nbsp; [4] mimiccing
- **设计亮点**：干扰项全部由【语法规则变异算法】动态生成，包含“漏加k”、“错加字母”、“错误双写”等真实考点陷阱。
- **快捷键**：键盘数字键 `1`, `2`, `3`, `4` 或 `A`, `B`, `C`, `D` 盲打秒选。

### 2. 题型二：全键盘纯拼写填空 (Spell-it-out Terminal)
- **场景**：高阶通关、错题二次过关。
- **题目呈现**：
  > 单词原形：**panic**  
  > 目标形态：**过去式 (-ed)**  
  > 输入框：`[ panick____ ]`  （支持回车确认或退格更正）
- **设计亮点**：彻底摆脱选项提示依赖，直接强化手部肌肉记忆与真实拼写能力。

### 3. 题型三：不规则阵营五分法槽位匹配 (Faction Sorter)
- **场景**：不规则动词专项战役。
- **题目呈现**：
  > 给出动词三态：**build → built → built**  
  > 请归属其不规则阵营：  
  > `[ AAA ]` &nbsp;&nbsp; `[ AAB ]` &nbsp;&nbsp; `[ ABA ]` &nbsp;&nbsp; `[ ABB (选中) ]` &nbsp;&nbsp; `[ ABC ]`
- **进阶变体**：给出原形 `read`，要求玩家判断其属于 `AAA`，并警示其发音变化（`/riːd/ → /red/ → /red/`）。

### 4. 题型四：词性天平辨析 (Syntax Role Duel)
- **场景**：深入理解现在分词/过去分词 vs 动名词。
- **题目呈现**：
  > 语境句子：*The **running** water is clean.*  
  > 提问：这里的 running 具有什么词性与语法功能？  
  > [A] 形容词词性（现在分词，修饰 water） &nbsp;&nbsp;&nbsp;&nbsp; [B] 名词词性（动名词，充当主语）  
  >  
  > 语境句子：*I enjoy **swimming** in the river.*  
  > [A] 形容词词性（现在分词） &nbsp;&nbsp;&nbsp;&nbsp; [B] 名词词性（动名词，作宾语）

## 三、五大游戏模式详述与规则机制

```
                                 ┌────────────────────────┐
                                 │      五大游戏模式体系  │
                                 └───────────┬────────────┘
                                             │
      ┌────────────────┬─────────────────────┼─────────────────────┬────────────────┐
      ▼                ▼                     ▼                     ▼                ▼
【模式1: 战役关卡】 【模式2: 艾宾浩斯复习】 【模式3: 弱点歼灭】   【模式4: 极速生存】 【模式5: 自由试炼】
循序渐进10大关卡    根据历史日期自动调度     错题本精准打击         限时抢答+无限连击   自定义筛选规则
建立系统语法大厦    对抗人类遗忘曲线         专治顽疾盲区           爽快测速突破极限   沙盒自由刷题
```

### 1. 战役闯关模式 (Campaign Mode - "时态符文之路")
包含 10 个精心编排的线性关卡，逐级解锁，初学者必刷：

| 关卡编号 | 关卡名称 | 考核核心规则与知识点 | 通关标准 |
| :--- | :--- | :--- | :--- |
| **Stage 01** | 现在分词初识 | 规则①：一般直接 +ing；规则②：不发音 e 去 e +ing | 10题 正确率 ≥ 80% |
| **Stage 02** | 拼写进阶变异 | 规则③：重读闭音节辅+元+辅双写 (run/stop)；规则④：ie变y (lie/die) | 10题 正确率 ≥ 80% |
| **Stage 03** | 隐秘刺客：-ic加k | **必考核心特例**：picnic, panic, frolic, mimic, traffic 加 k 变形 | 10题 正确率 ≥ 90% |
| **Stage 04** | 过去式四路军 | 规则①：+ed；规则②：+d；规则③：双写+ed；规则④：辅音+y变ied | 12题 正确率 ≥ 85% |
| **Stage 05** | 第三人称单数 | 规则①：+s；规则②：s/x/sh/ch/o +es；规则③：y变ies；规则④：真不规则 be/have | 12题 正确率 ≥ 85% |
| **Stage 06** | 不规则·基础三阵营 | **AAA型** (cost/put/cut/hit/let/read) + **AAB型** (beat) + **ABA型** (come/run/become) | 15题 正确率 ≥ 85% |
| **Stage 07** | 不规则·中流砥柱 | **ABB型大军** (find, leave, feel, keep, sleep, build, send, teach, buy, think等) | 18题 正确率 ≥ 85% |
| **Stage 08** | 不规则·千面百变 | **ABC型精选** (go, do, see, eat, fall, take, give, write, break, choose, forget等) | 18题 正确率 ≥ 85% |
| **Stage 09** | 词性法庭 | 区分【分词=形容词性】与【动名词=名词性】的应用语境辨析 | 10题 正确率 ≥ 80% |
| **Stage 10** | 终极炼金大宗师 | 全题库完全随机大乱斗，混杂所有变异规则与高难陷阱 | 25题 正确率 ≥ 92% |

### 2. 每日艾宾浩斯复习模式 (Daily Spaced Repetition)
- **触发条件**：根据系统日期，自动扫描本地日志中 `next_review_date <= 当天 23:59:59` 的词条。
- **推荐标识**：主界面高亮闪烁【今日待复习: X 词】黄金徽章。
- **复习机制**：
  - 单次复习量限制为 15~30 题（避免认知疲劳）。
  - 若答对：记忆阶段（Phase）提升 1 级，下次复习日期顺延到新的间隔周期。
  - 若答错：记忆阶段直接重置为 Level 1，并在本次复习 session 的尾声再次出现直至答对。

### 3. 弱点歼灭战模式 (Weakness Strike / Boss Rush)
- **目标**：定点爆破错题。
- **题源筛选**：
  1. 历史累计错误次数 $\ge 2$ 的单词；
  2. 个人历史正确率 $< 60\%$ 的单词；
  3. 距离上次答错且至今尚未答对过的词条。
- **通关机制**：将错题库清零即为大获全胜，并移出错题高危预警区。

### 4. 极速生存模式 (Speed Sprint / Endless Combo)
- **机制**：
  - 玩家初始拥有 3 颗心 (HP)；
  - 每题倒计时 6 秒，时间走完或选错扣除 1 颗心；
  - 连续答对 5 题恢复 1 颗心并进入“狂暴得分 (Frenzy Mode)”；
  - 统计单局最大连击数 (Max Combo) 与最终生存得分，记录在个人高分榜上。

### 5. 自由沙盒试炼 (Free Lab Sandbox)
- **高度客制化**：用户可手动勾选：
  - 【规则过滤器】：如“只练 -ic 结尾加 k”或“只练 ABB vs ABC”。
  - 【作答方式】：选择题 vs 纯键盘打字。
  - 【题量设定】：10 题 / 20 题 / 50 题 / 无限练习。

## 四、基于日期的艾宾浩斯记忆模型算法规范

系统根据用户练习日期与结果，为每一个词条赋予独立的记忆状态元数据：

```json
{
  "word_id": "panic_past",
  "base_verb": "panic",
  "rule_id": "RULE_ED_IC_SPECIAL",
  "level": 3,
  "last_practiced_date": "2026-10-06T10:15:00.000Z",
  "next_review_date": "2026-10-10T10:15:00.000Z",
  "total_attempts": 6,
  "success_count": 5,
  "failed_count": 1,
  "streak": 3,
  "stability_days": 4
}
```

### 1. 记忆等级与天数间隔矩阵 (Memory Schedule Table)

| 记忆等级 (Level) | 称号与认知状态 | 成功后复习间隔天数 (Interval) | 答错降级惩罚 |
| :--- | :--- | :--- | :--- |
| **Level 0 (Unseen)** | 未接触新词 | 0 天 (随时可学) | - |
| **Level 1 (Novice)** | 初次接触 | +1 天 (明天复习) | 保持 Level 1 |
| **Level 2 (Learner)** | 初步建立印象 | +2 天 (2天后复习) | 降为 Level 1 |
| **Level 3 (Competent)** | 掌握规则模式 | +4 天 (4天后复习) | 降为 Level 1 |
| **Level 4 (Proficient)**| 形成语感条件反射 | +7 天 (1周后复习) | 降为 Level 2 |
| **Level 5 (Master)** | 永久长时记忆 | +15 天 (半月后复习) | 降为 Level 3 |
| **Level 6 (Legend)** | 终极巩固封神 | +30 天 (1月后抽查) | 降为 Level 4 |

### 2. 状态判定算法伪代码

```typescript
function calculateWordStatus(card: WordMemoryCard, currentDate: Date): WordStatus {
  if (card.total_attempts === 0) return 'NEW';
  
  const daysDiff = (currentDate.getTime() - new Date(card.next_review_date).getTime()) / (1000 * 3600 * 24);
  
  // 逾期超过间隔的 2 倍以上，判定为生锈濒危
  if (daysDiff > card.stability_days * 2) {
    return 'RUSTY'; // 记忆生锈
  }
  
  // 到期需复习
  if (daysDiff >= 0) {
    return 'DUE_FOR_REVIEW'; // 今日到期
  }
  
  // 达到高熟练度
  if (card.level >= 5) {
    return 'MASTERED'; // 已永久掌握
  }
  
  return 'CONSOLIDATING'; // 巩固中 (冷却期内)
}
```

## 五、知识覆盖率与巩固指标计算体系

系统主界面展示三大核心指标看板：

### 1. 词汇覆盖率 (Vocabulary Coverage Rate)
$$\text{Coverage Rate} = \frac{\text{已练习词汇数 (至少练过1次)}}{\text{题库全部词汇总数}} \times 100\%$$

### 2. 规则掌握度 (Rule Mastery Rate)
每个规则（如 `-ic变k`、`重读闭音节双写`）计算综合得分：
$$\text{Rule Mastery Score} = \frac{\sum \text{该规则下单词的有效正确次数}}{\sum \text{该规则下单词的尝试总次数}} \times 100\%$$
- 若某规则练习次数 $\ge 10$ 次且得分 $\ge 85\%$，该规则亮起【已掌握徽章】。

### 3. 全局记忆健康度 (Global Memory Health Index)
衡量当前大脑中所有学过词汇的抗遗忘健康水平：
$$\text{Health Index} = \frac{\text{巩固中词数} \times 1.0 + \text{已掌握词数} \times 1.2 - \text{生锈词数} \times 0.8}{\text{已学词汇总数}} \times 100$$
（健康度动态呈现在主界面的生命水晶/符文球中，低于 60% 时水晶变黯淡并提醒充电复习）。
