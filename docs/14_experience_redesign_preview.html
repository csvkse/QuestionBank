一、规则变形核心考点 › 以 -ic 结尾动词的特殊变位
Layer 1: 基础认知
CORE TARGET ENTITY

picnic (野餐)

标准变形：picnicked / picnicking

以字母组合 -ic 结尾的动词，在加 -ed 或 -ing 前，必须先加 k，以保持软硬音 /k/ 的发音规则一致性。

同胞干扰项横向比对矩阵 (Sibling Distractors Matrix)

❌ picniced
高频笔误：直接加 ed 会导致 c 发 /s/ 音，不合发音规则
❌ picnicced
类比误判：误以为双写末尾辅音字母 c
✅ picnicked
唯一正确标准答案（正向心理表征）
高频命题陷阱 (Pitfalls & Mnemonic Anchor)

类似同类词汇还包含：panic ➔ panicked, traffic ➔ trafficked。中考、高考及考研阅读常作为干扰选项设计！
